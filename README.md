# Сад под сакурой

Готовая статическая версия для GitHub Pages. Сборка, npm и GitHub Actions не требуются. Музыка, изображения, шрифт и код включены. Все пути относительные, сайт работает по адресу вида https://USERNAME.github.io/sakura-garden/.

## Размещение через браузер

1. Войди в GitHub и создай репозиторий `sakura-garden`: https://github.com/new . На бесплатном плане для Pages нужен Public. Включи Add README и нажми Create repository.
2. Распакуй архив и открой папку `sakura-garden`. В ней находятся `index.html`, другие файлы и папка `assets`.
3. В репозитории выбери Add file → Upload files. Перетащи **содержимое** папки `sakura-garden`, включая всю папку `assets`. Саму внешнюю папку и ZIP не загружай. `index.html` должен находиться в корне репозитория.
4. Нажми Commit changes. Существующий README можно заменить этим файлом.
5. Открой Settings → Pages. В Build and deployment выбери Source: Deploy from a branch; Branch: main; Folder: /(root). Нажми Save.
6. Дождись публикации. Адрес появится в Settings → Pages, кнопка Visit site. Первый запуск может занять до десяти минут.

Обычный GitHub Pages доступен всем по ссылке, даже при приватном репозитории на платном плане. Личные записки также будут доступны посетителям. `noindex` и `robots.txt` просят поисковики не индексировать сайт, но не закрывают доступ.

## Обновление

Замени изменённые файлы в той же структуре и создай новый commit в `main`. GitHub обновит сайт автоматически. Не переименовывай папку `assets` и не удаляй её подкаталог `music`.

## Проверка

Открой опубликованный адрес, загляни в главное письмо и несколько записок. Для запуска музыки нажми на кнопку музыки или выбери композицию: браузер требует действие пользователя. Проверь поворот экрана на телефоне.

Если вместо сада отображается README или ошибка 404, проверь положение `index.html` и настройки `main` / `/(root)`. Открытие `index.html` двойным щелчком через file:// не подходит из-за ES-модулей: проверяй сайт через опубликованный адрес.
